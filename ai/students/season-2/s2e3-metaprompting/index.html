S2E3 MetaPrompting

Let the AI interview you, then build the prompt from your answers

What this lesson is about

The hardest moment to write a good prompt is when you are most stuck, with a rough topic but no clear argument yet. This lesson solves that with two techniques. Meta-prompting uses AI to help build the prompt itself rather than write the final answer. The Flipped Interaction Pattern has the AI ask you questions first, so your answers become the prompt. By the end you will have a detailed prompt built entirely from your own thinking, and the Gem will use it to produce a structured essay outline.

What you'll be able to do

  • I can use the Flipped Interaction Pattern and Meta-Prompting to build a precise prompt that directs AI to produce a structured academic essay outline from my own thinking.
  • I can describe the difference between stochastic and deterministic systems and explain why this matters when testing AI prompts.

You will also learn why the same prompt can give different answers each time. A calculator is deterministic, it always returns the same result for the same input. AI language models are stochastic, with randomness built into how they choose each word, which is why testing a prompt in a fresh conversation is more reliable than testing it where you built it.

Key words

Meta-prompting
Using AI to build the prompt itself, rather than to write the final answer.
Flipped Interaction Pattern
The AI asks the questions first. Your answers become the prompt.
Deterministic
Same input, same output, every time. A calculator is deterministic.
Stochastic
Randomness is built into how each word is chosen, so the same prompt can answer differently twice.
