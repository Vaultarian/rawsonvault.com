Data Representation of Sound

Real sound files you can hear, and whose size you can calculate to the exact byte.

The idea

Every sound below is a real file, stored as a WAV. A WAV stores every sample with no compression, plus a 44-byte header at the front: the metadata that records the sample rate, the bit depth and the length. That header is always 44 bytes.

file size (bytes) = sample rate × seconds × bit depth ÷ 8 + 44

Check it yourself

  1. Work out the file size in bytes with the formula, before you look.
  2. Download the file with the link under the player (or the player's ⋮ menu, then Download).
  3. Find the saved file. On Windows, right-click it and choose Properties: the Size line shows the exact number of bytes.
  4. Open Check your answer and compare all three numbers.

Use headphones if the room is busy.
