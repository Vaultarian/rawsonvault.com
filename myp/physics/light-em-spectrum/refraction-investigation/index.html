A

The apparatus and the card

Reflection is what light does when it bounces off a surface. Refraction is what light does when it passes into a new material. Together they explain every mirror, lens, pair of glasses and camera.

That light changes direction is easy to see. The investigation asks how much it bends, and what decides that.

How to read the card

  • Aim the ray at the centre of the card.
  • Read the top scale for the angle going in, θ₁.
  • Read the bottom scale for the angle coming out, θ₂.
  • The normal is 0°. Both scales count away from it.

The first check to make

The 0° row reads 0°. A ray along the normal goes straight through, so a table that starts anywhere else was read from the wrong scale.

C1

Your graph: a line of best fit, not join the dots

Every measurement carries a small error, so real points sit a little above and below the true pattern. A graph should show the pattern.

Four things the marker looks for

  • Axis numbers evenly spaced.
  • Both axes labelled, with units.
  • Points plotted accurately.
  • A ruler used for the axes, and one smooth curve through the middle of the points.

Both variables are numbers, so this is a scatter graph with a line of best fit. A bar chart is for when the thing you changed is words.

To go further: explain it

The best conclusions explain what is happening to the light, as well as what the graph does.

Light travels more slowly in perspex than in air, so the wave fronts squash closer together. The side of the ray that reaches the boundary first slows down first while the other side is still going quickly, so the ray swings round towards the normal. The bigger the angle of incidence, the bigger that head start between the two sides, so the more the ray turns.

Watch the left end of each front slow down as it enters the block. Change the angle and compare.
